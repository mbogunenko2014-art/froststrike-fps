# 🍌 Banana AI — ассистент на собственном движке

Один самодостаточный HTML-файл: `banana-ai/index.html`. Скачай → открой локально в Chrome / Firefox / Edge. Работает без установки, без сервера, без сборки.

## Честно о главном

- **Никаких сторонних ИИ.** Ни OpenAI, ни DeepSeek, ни других API. Движок собран с нуля и живёт внутри этого файла.
- **Это не нейросеть.** Честный классический движок: стеммер → классификатор намерений → база знаний → умения. На вопрос «ты нейросеть?» Banana сама отвечает правду.
- **Объём:** ~1823 строки — все рабочие, без накрутки пустышками.
- **Онлайн-справочники** — только Википедия и курсы валют, по желанию выключаются в настройках (тогда 100% офлайн). Курсы валют при недоступности сети показывают вшитую таблицу с честной пометкой даты.

## Умения

| Категория | Примеры запросов |
|---|---|
| Математика (безопасно, без eval) | «сколько будет 2+2*2», «корень из 144», «5!», «15% от 200», «5 умножить на 4 плюс 3» |
| Конвертер единиц | «5 км в мили», «30 c в f», «2 кг в фунты», «500 МБ в гб» |
| Дата и время | «который час», «какое сегодня число», «сколько дней до Нового года» |
| Генераторы | «пароль 16», «монетка», «кубик d20», «случайное от 1 до 100», «выбери: а, б, в» |
| Текст | «транслит: привет», «сколько слов: …», base64 encode/decode |
| База знаний (~97 тем) | «расскажи про Луну», «что такое ДНК», «кто такой Гагарин», «как учиться» |
| Развлечения | «шутка», «факт», «подбодри» |
| Память | «меня зовут Вася» → потом «как меня зовут?»; «я люблю аниме» — запомнит вкус |
| Фолбэк | если темы нет в базе — Википедия (если включена) или честное «не знаю» |

## Как устроен движок (6 пунктов)

1. Свой лёгкий русский стеммер (обрезка окончаний, стоп-слова).
2. Свой классификатор намерений: 20 намерений, взвешенные фразы, порог срабатывания.
3. Вшитая база знаний: космос, наука, техника, история, здоровье, повседневное. Поиск — по пересечению стемов (ключи весят больше).
4. Безопасный калькулятор: собственный токенизатор + сортировочная станция + ОПЗ, **никакого eval**. Защита от телефонных номеров («8-800-…» не считается).
5. Память: настройки, диалоги и факты о пользователе — только в localStorage твоего браузера. Ничего не отправляется.
6. Онлайн — исключительно Википедия/валюты с выключателем.

## Интерфейс

- Печать ответа «как живой человек» (скорость 0/1/2 в настройках), кнопка «стоп».
- Несколько диалогов с историей, удаление каждого, новый диалог.
- Экспорт диалога в Markdown.
- Настройки: обращение, стиль ответов, пожелания к характеру, скорость печати, онлайн-справочники.
- Кнопка «Проверить движок» — гоняет самотесты умений и ядра прямо в интерфейсе.

## Надёжность

- Сторож запуска в отдельном `<script>`-блоке: если основной скрипт упал, покажет честную красную панель с собранными ошибками.
- Сборщик ошибок с первой строки (window.onerror + unhandledrejection).

## Тесты (jsdom-смоук, 28/28 PASS)

- Полный запуск документа: движки BA2/BA3/BAU живы, ошибок нет.
- Самотесты: умения 4/4, ядро 6/6 (приветствие, память имени, база знаний, шутка, честное «не нейросеть»).
- Через интерфейс: математика, база знаний, честный фолбэк офлайна, Enter-отправка, чипсы, история, новый диалог, настройки (сохранение + скорость), самотест в UI, экспорт без крэша.
- Негативный тест: без главного скрипта сторож показывает панель ошибки (~6 с).
- 5 JS-блоков, каждый прошёл `node --check`; внутри кода нет литеральных `</script>`.

## Запуск

1. Скачай `banana-ai/index.html` (кнопка Download в PR / Raw → сохранить как).
2. Открой файл двойным кликом в свежем Chrome / Firefox / Edge.
3. GitHub-страница не запускает приложение — файл нужно открыть локально.
