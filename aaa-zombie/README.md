# ZOMBIE 300K — процедурный реалистичный зомби-персонаж

Один самодостаточный HTML-файл: `aaa-zombie/index.html` (~1900 строк). Без библиотек, без сборки, без сервера, без интернет-зависимостей.

## Честные цифры (посчитаны кодом, см. панель статистики)

- **291 276 треугольников** — запрошенный диапазон 250 000–300 000 соблюдён
- **148 312 уникальных вершин** — индексированная геометрия (32-битные индексы, OES_element_index_uint)
- **36 деталей** собираются по очереди с прогрессом «деталь: …»
- **18 костей скелета** — настоящая скелетная анимация (взвешенный skinning в вершинном шейдере)
- **9 анимаций**: Дыхание, Ходьба, Хромота, Бег, Поворот головы, Осматривается, Атака, Падение, Подъём
- Модель детерминированно процедурная: ни одного загруженного файла, собирается кодом при запуске

## Анатомия (всё смоделировано как отдельная геометрия)

Голова (череп с надбровными дугами, впалыми щеками, глазницами, зубочелюстными деформациями и асимметрией), отдельная нижняя челюсть (открывается в анимации атаки), шея, торс с животом и асимметрией грудной клетки, 2 руки: плечо/предплечье/кисть/пальцы (4 пальца + большой, отдельные фаланги, отдельные ногти), 2 ноги: бедро/голень (с икрой)/ступня/пальцы ног, глаза (мутные, с радужкой и красными прожилками — шейдер), веки, уши, нос, зубы верх/низ с клыками, язык, полость рта, сальные волосы, бетонная плита.

## Ткани и кожа — шейдеры

- Кожа: бледно-нездоровая, mottling (пятна гнили), вены под кожей, поры и морщины (рельеф по тангенсу), 4 раны-кратера (грудь, щека, предплечье, живот), 2 шрама, wrap-освещение + приблизительный subsurface scattering (красный просвет на контровом свете)
- Рубашка: ветхая ткань с тканным узором, грязью, кровяными пятнами, рваным низом и кромкой рукавов; складки геометрией
- Брюки: мешковатые, грязь/мазут у подола, рваные кромки; ремень; ботинки

## Управление

- Мышь: drag — вращение, колесо — зум; сенсор: палец — вращение, щипок — зум
- Клавиатура: стрелки, «+»/«−»
- Кнопки: смена анимации, пауза, каркас (wireframe, ленивый честный дедуп рёбер), 4 световых пресета (Лунная ночь / Морг / Адское зарево / Сумерки), скриншот PNG, сброс камеры, автоповорот
- Статистика в реальном времени: треугольники, вершины, детали, FPS, текущая анимация

## Честность запуска (уроки Gektar/ZombieTub/Draco)

- Прогресс-бар по деталям; при отсутствии WebGL — честная панель (не чёрный экран)
- Сторож-скрипт в отдельном блоке: если главный скрипт упал — красная плашка «ZOMBIE — ошибка запуска» с текстом ошибок
- Коллектор ошибок window.__ZTerrs + toasts

## Чего здесь НЕТ (честно)

- Нет 8K-карт текстур (Base/Normal/Roughness/AO/Displacement): детализация сделана шейдерами — в одном HTML-файле «фототекстуры» физически нечестно притворять; всё, что заявлено, — процедурный шейдинг
- Нет экспорта в UE5/Unity/FBX: это браузерный продукт-просмотр, а не производственный ассет
- Нет рига с экспортом и facial-bones: скелет живёт внутри веб-приложения (18 костей + независимая челюсть), анимации — процедурные позы, не мокап-клипы
- Нет фотограмметрии и сканов: «AAA-реализм» в одном файле — это 291k треугольников + SSS/вены/раны/ткани в шейдере, не фотоскан
- В реальном браузере не тестировали (окружение без Chrome): проверены геометрия/математика/честные ветки, GPU-путь падает с честным сообщением

## Запуск

Скачай `index.html` и открой двойным кликом в Chrome/Firefox/Edge/Safari. Требуется WebGL + OES_element_index_uint (все современные десктопные и мобильные браузеры поддерживают). Страница на GitHub ≠ работающее приложение.
