# NEXUS AI CAMERA

Интеллектуальная камера для телефона — **один цельный HTML-файл** (`index.html`, ~95 КБ). Никаких сборок и зависимостей: открой файл по HTTPS — и камера работает.

## Ключевая идея
Фотографируешь → снимок **автоматически обрабатывается** (нейросети + алгоритмы улучшения) → **готовая улучшенная версия высокого качества появляется в галерее**. Оригинал тоже сохраняется.

## Камера (getUserMedia)
- Живое превью, переключение фронтальная/основная камера (двойной тап по экрану тоже переключает)
- Фото, запись видео (MediaRecorder, mp4/webm), таймер 3/5/10 с, вспышка-фонарик (где поддерживается)
- Зум: аппаратный или гибридный (пинч-жест + кнопки 1×/2×/3×/5×)
- Фокус и экспозиция по тапу (points of interest), ползунок экспокоррекции
- Баланс белого: авто/день/пасмурно/тепло/холодно (где поддерживается камерой)
- Выбор разрешения (Авто/1080p/720p/4K), сетка-композиция, полноэкранный режим
- **QR-сканер** (кнопка QR в верхней панели): реальное распознавание QR-кодов с живой камеры через библиотеку [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0, загружается с CDN при первом включении) — рамка прицела, кнопки «Открыть ссылку», «Копировать», «Поделиться», и не блокирует съёмку
- Понятные экраны ошибок (нет доступа, камера занята, нужен HTTPS) + резервный путь: снимок системной камерой

## Реальный AI (без бутафории)
Нейросети (реальные модели, загружаются с CDN лениво, в момент первого использования):
- **COCO-SSD** — распознавание объектов и сцены (подписи на русском)
- **BlazeFace** — поиск лиц для портретного эффекта
- **U²-Net (imgly/background-removal)** — вырезание/замена/блюр фона

Алгоритмы обработки (реальные, на пикселях canvas):
- авто-баланс белого (gray-world), авто-уровни по гистограмме, гамма-экспозиция
- шумоподавление (edge-aware билатеральный фильтр), локальный контраст (HDR), ночной режим
- юншарп-маска резкость, апскейл с пост-резкостью, виньетка

AI-API (реальное подключение, без ключа):
- онлайн-модель описывает сцену текстом (можно включить/выключить)
- архитектура: `apiDescribe()` — единая точка для подключения любого vision-API в будущем

Честные подписи: всё, что считается алгоритмом, помечено как алгоритм; нейросети — с указанием модели. Если нейросеть недоступна (нет сети при первом запуске) — приложение сообщает об этом, а не имитирует работу.

## Редактор
Коррекция: яркость, контраст, насыщенность, температура, оттенок, света, тени, резкость, размытие, виньетка.
Инструменты: обрамление (crop с ручками), поворот 90°, отражение, фон (нейросеть), блюр фона, распознать объекты, описать сцену (API), апскейл 2×.
Фильтры: Кино, Профи, Винтаж, HDR, Натуральный, Арт (превью-миниатюры).
Undo/Redo (10 шагов), сравнение «до/после» удержанием кнопки, сохранение как новой версии с хранением оригинала.

## Галерея
IndexedDB (данные остаются на устройстве): сетка фото и видео, просмотр, редактирование, удаление с подтверждением, скачивание, «Поделиться» (Web Share API с файлами, иначе скачивание), скачивание оригинала, метки распознанных объектов и AI-описание.

## Мобильный дизайн
Тёмная премиальная тема, глассморфизм, скруглённые контролы, safe-area для вырезов, крупные цели нажатия (44–76px), без горизонтального прокрута, плавные анимации. Портрет и ландшафт.

## Тесты
Headless-смоки (jsdom): `24/24 PASS` (ядро, пиксельные алгоритмы, IndexedDB, галерея), `24/24 PASS` (полный конвейер: авто-обработка → редактор → сброс → сохранение → просмотр → удаление).

## Запуск
Открой `index.html` по HTTPS (например, GitHub Pages) в Chrome/Edge/Safari на телефоне. Firefox поддерживается, кроме управления вспышкой/зумом камеры (ограничение браузера).

## v1.1 — исправления
- Пинч-зум и жесты камеры больше не конфликтуют с масштабированием страницы (touch-action)
- Вспышка «авто» зажигается ДО снимка, тушится после — свет действительно попадает в кадр
- Таймер можно отменить повторным нажатием кнопки спуска; защита от двойного срабатывания
- Конвейер быстрее: табулированные веса шумодава, 1 проход размытий, предпросмотр редактора рендерится в уменьшенном разрешении, а при сохранении — полное
- Fallback разрешения: если выбор 4K/1080p не поддержан, камера перезапускается с настройками по умолчанию вместо ошибки
- Обрезка сохраняет полное разрешение исходника; инструмент «Сброс»; корректное сохранение PNG с прозрачностью после удаления фона

## Лицензии использованных библиотек
- TensorFlow.js, COCO-SSD, BlazeFace — Apache-2.0
- @imgly/background-removal — см. репозиторий библиотеки
- jsQR — Apache-2.0 (cozmo/jsQR)
Все библиотеки подгружаются с публичного CDN (jsdelivr) при первом использовании функции.
