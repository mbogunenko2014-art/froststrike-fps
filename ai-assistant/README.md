# NEXUS AI —_browser assistant in one file

Single-file web AI chat (HTML + CSS + vanilla JS, no build step, no frameworks).

- Live LLM via free keyless `text.pollinations.ai` (OpenAI-compatible, SSE streaming) — answers any question like mainstream AI assistants
- Offline fallback engine: math evaluation, date/time, coin/dice, persistent notes («запомни…»), small talk
- 6 personas (assistant/coder/teacher/translator/writer/custom), model picker (fetched live), temperature, streaming toggle, optional API key (stored locally, raised limits)
- Markdown-lite rendering with code blocks + copy buttons, chat history in localStorage, regenerate, stop generation, TXT export, dark/light theme, fully responsive
