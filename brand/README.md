# BANANA AI — брендбук

Весь бренд компании BANANA AI в одном самодостаточном HTML-файле: `index.html`.
Никаких зависимостей, сборки, шрифтов извне и картинок — вся графика нарисована
кодом как векторный SVG прямо в файле.

## Что внутри (все 10 пунктов ТЗ)

1. **Главный логотип** — жёлтый банан с толстой чёрной обводкой + надпись BANANA AI.
2. **Вариации логотипа** — горизонтальный, вертикальный, только иконка, чёрно-белый,
   жёлто-чёрный, версия для тёмного фона, фавиконки (128/64/48/32 px). Банан во всех
   вариантах один и тот же: он описан один раз в `<defs>` (`#banBody` / `#banMono`)
   и везде используется через `<use href="#banBody">` — силуэт гарантированно не «плывёт».
3. **Иконка приложения** — скруглённый квадрат, жёлтый фон, читается на 48×48.
   Показаны превью 128/64/48/32 px и три темы (тёмная/светлая/жёлтая).
4. **Маскот** — банан с минимальным лицом и крошечной ИИ-антенной. 4 выражения:
   нейтральный / радостный / думает / загрузка — переключаются кнопками, у каждого
   есть описание.
5. **Палитра** — #FFD600, #111111, #FFFFFF, #F5F5F5, #222222. Клик по образцу
   копирует HEX-код в буфер обмена.
6. **Типографика** — геометрический гротеск (системный стек Inter → Segoe UI → Arial,
   чтобы файл открывался офлайн), образцы H1/H2/Body/Caption/моно-цифры.
7. **Графические элементы** — мини-банан, медальон, плашка, ракушка 2×2, бесшовный
   паттерн из бананов, 4 контурные иконки, кольцо и точки загрузки.
8. **Загрузочный экран** — тёмная и светлая темы, логотип по центру, покачивающийся
   банан, прогресс-бар со счётчиком 0→100%, кнопка «проиграть снова».
9. **Соцсети** — аватар профиля, Telegram-аватар, шапка YouTube, шаблон поста,
   промо-баннер.
10. **Презентация** — всё выше на чистых белых макетах с оглавлением в шапке.

## Честные факты

- **Объём: 943 строки** — реальное число, без накрутки. Внутри: CSS-система,
  SVG-библиотека, разметка всех макетов и рабочий JS.
- **Градиентов нет** — только плоские цвета из палитры, как в ограничениях ТЗ.
- **Каждая кнопка рабочая:** копирование цвета, скачивание любого SVG (12 файлов —
  каждый скачивается самодостаточным: канонический банан встраивается в файл,
  `<use>`-ссылки не ломаются), переключение выражений маскота, перезапуск
  анимации загрузки, смена темы экрана загрузки.
- **Мобильная адаптация:** брейкпоинты 720px и 400px, меню со горизонтальной
  прокруткой, сетки в одну колонку, `prefers-reduced-motion` отключает анимации.
- Собираются ошибки (`window.__BAerrs`) — если что-то упадёт, это видно.

## Как запустить

Скачай `index.html` (кнопка «Download» в PR или Raw → сохранить) и открой
двойным кликом в любом браузере. Интернет не нужен. Страница на GitHub —
это просто просмотр кода, открывать файл надо локально.

## Проверки

- Синтаксис обоих `<script>`-блоков: `node --check` — OK.
- Smoke на jsdom: **32/32 PASS** (загрузка, экспорт, все id, кнопки, палитра,
  маскот, тосты, навигация, счётчик загрузки) + отдельная проверка содержимого
  скачиваемых SVG (самодостаточность, viewBox, встройка банана) — PASS.
