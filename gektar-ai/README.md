# GEKTAR AI — Intelligence Beyond Imagination

Полноценная AI-платформа для написания кода в **одном самодостаточном HTML-файле** (`index.html`, 7 866 строк). Без сборки, без зависимостей, без npm — скачайте файл и откройте в браузере (Chrome / Edge / Firefox / Safari), работает и с компьютера, и с телефона.

## Что внутри

**Фирменный ASCII-глаз.** Центральный символ платформы генерируется процедурно по формуле (сетка 31×11, ~217 непустых символов) и живёт в шести состояниях: IDLE (дыхание, мерцание символов, частицы, моргание), THINKING (сканирование, красная линия скана), CODING (перестановка символов, пульсы синхронно с работой ИИ), SUCCESS (красно-белый пульс), ERROR (глитч), LOGIN (сборка символов из центра).

**Лендинг.** Тёмная тема (#050505 / #101010 / акцент #E50920), герой с анимированным глазом, теглайн, кнопки, статистика, секции возможностей и языков, красные частицы, сетка, scroll-анимации.

**Авторизация.** Регистрация и вход с валидацией, показ/скрытие пароля, «запомнить меня», восстановление пароля по контрольному слову, постоянная сессия, ошибки по полям. Честная реализация: пароли хранятся как **SHA-256 хэш** (crypto.subtle; в средах без TLS/или http — двойной FNV-1a fallback в localStorage). Это клиентская аутентификация, а не серверная — бэкенд в статичном репозитории невозможен, обманывать пользователя фейковыми кнопками мы не стали.

**Дашборд.** Сворачиваемый сайдбар (New Chat / AI Coding / Projects / Code History / Saved Files / Plugin Store / Settings / Profile), приветствие «Что строим сегодня?», большой промпт, вложения (файлы + изображения), выбор модели, боковая панель проекта, мобильная навигация.

**Чат с ИИ.** Стриминговые ответы, Markdown-рендер с кнопками «копировать», память («запомни…», «что ты помнишь», «забудь всё»), вложения-изображения (даунскейл 512px → vision-модель), источники, остановка генерации, история чатов, черновик ввода.

**Бригада генерации кода** (главная фича): Architect (план архитектуры) → Builder (многофайловая генерация) → Reviewer (замечания) → Builder (исправления) → статические проверки → Verifier (до 2 раундов, пока не получит «ПРОВЕРКА ПРОЙДЕНА»). Результат попадает в проект как файлы (index.html / style.css / script.js …), открывается рабочее пространство, в лог сборки честно пишется: код проверен статическим анализом и песочницей, но не запускался в реальности.

**Рабочее пространство кодинга.** Слева — проводник (создание файлов и папок, переименование, удаление, поиск, защита index.html), в центре — редактор (подсветка синтаксиса HTML/CSS/JS, нумерация строк, автоотступы, автозакрытие скобок, вкладки, Ctrl+S, Ctrl+Enter → превью, автосохранение, версии проекта до 10), справа — ИИ-ассистент (объяснить / найти ошибки / исправить / улучшить / документация, применение правок с подтверждением и снимком версии), снизу — терминал (help/ls/tree/open/cat/rm/run/build/clear, история по стрелкам), консоль, панель ошибок, вывод сборки.

**Живое превью.** Песочница `sandbox="allow-scripts"`: сборка проекта в один HTML (инлайн `link` и `src`), режимы Desktop / Tablet / Mobile, обновление, полный экран, скачивание проекта, мост ошибок — реальные `window.onerror`, unhandledrejection и перехваченный console.* из превью попадают в панели консоли и ошибок IDE.

**Магазин плагинов** (7 встроенных рабочих плагинов):
- **Video Studio** — генерация анимированного видео на canvas + `MediaRecorder`, экспорт в WebM;
- **Agent Workspace** — ИИ делит сложную задачу на 3–6 шагов (JSON) и выполняет их последовательно с прогрессом в логе;
- **Security Scanner** — статический аудит проекта: eval, new Function, inline-обработчики, innerHTML, http-ссылки, внешние скрипты, утечки секретов;
- **Vision Scanner** — распознавание содержания изображения через vision-модель;
- **Presentation Maker** — генерация презентации (тёмные/красные слайды) в файл проекта;
- **Memory Keeper** — сохранение фактов и контекста, факты автоматически подмешиваются в контекст чата;
- **Code Brigade** — маршрутизация в бригадную сборку проекта.

Плагины включаются/выключаются переключателями, состояние сохраняется.

**Настройки.** Аккаунт (смена пароля, выход), внешний вид (интенсивность красного акцента 1–4, анимации full/low, компактность, размер шрифта редактора), ИИ-модели, статус ИИ (бесплатные модели без ключа либо свой OpenAI-совместимый/DeepSeek ключ — **ключ хранится только локально и никогда не выводится в DOM**), настройки кода (табуляция, скобки, автосохранение), редактор, уведомления, приватность (полная очистка данных), о программе.

## Модели ИИ

По умолчанию — бесплатные безключевые модели через `text.pollinations.ai` со списком и каскадом: Architect, Builder, Reviewer, Verifier, Chat — у каждого свой приоритет моделей (openai-large, deepseek, qwen-coder, mistral, llama…). Можно подключить свой ключ DeepSeek в настройках — тогда запросы идут напрямую в `api.deepseek.com`. Архитектура провайдеров модульная, стриминг SSE, отмена запросов, таймауты.

## Честность

- Сгенерированный ИИ код **не запускается в реальности** — проверяется статическим анализом (проверки пустоты, заглушек, расцепления скобок, остатков маркдауна) и песочницей превью с мостом ошибок. Это указано в логе сборки.
- Аутентификация клиентская (см. выше), без сервера.
- Тестирование: jsdom-смоук **69/69 проверок** (вход/регистрация, глаз, чат со стримингом, бригада — полный цикл до трёх файлов, редактор, терминал, сборка превью, мост ошибок, настройки, списки, плагины, выход), `node --check` на JS-модуле, prettier-форматирование. В браузере всё код-обзором и смоуком не покрыто — если что-то поведёт себя не так, скажите, поправим.

## Запуск

1. Скачайте `index.html` (кнопка Download /RAW в GitHub).
2. Откройте двойным кликом в браузере.
3. Зарегистрируйтесь и начните строить.
