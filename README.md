# FrostStrike FPS

Browser FPS in a single HTML file (HTML + CSS + JavaScript + Three.js r160, loaded via CDN import map).

## Run
Open `index.html` in any modern browser (internet required for the Three.js CDN import).

## Features
- 5 maps: Snow Arena, Neon City, Industrial Zone, Desert Arena, Training Ground
- 7 weapons: knife, pistols, SMG, rifles, shotguns, sniper rifles, grenades
- 8 skins, 5-round matches vs bots with AI, score/timer/health/ammo
- Full HUD (FPS, crosshair, health, ammo, killfeed) and pause
- PC controls: WASD, mouse, LMB, R, Space, Shift, 1-5, Esc
- Mobile controls: virtual joystick, swipe camera, fire/jump/reload/swap/crouch buttons
- Settings: sensitivity, quality, FOV, force mobile controls
