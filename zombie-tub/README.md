# 🧟 ZombieTub — зомби-ютуб

Один самодостаточный файл: `zombie-tub/index.html` (≈1760 строк). Без сборки, без сервера, без зависимостей. Скачай → открой в браузере → глядь.

## Что это честно, а что нет

- ❌ **«Все видео ютуба» — технически невозможно** (миллиарды роликов, ютуб их не скачивает). ZombieTub — это оболочка-клиент: она **ищет и играет настоящие видео с ютуба** через открытые зеркала.
- ✅ **Настоящие видео**: поиск и воспроизведение через публичные API-зеркала **Piped / Invidious** (8Mirrors: kavin.rocks, private.coffee, adminforge, projectsegfau, drgns.space, nadeko.net, nerdvpn.de, yewtu.be).
- ✅ **Без рекламы** — пока работает прокси-плеер (поток с зеркала).
- ✅ **Честный fallback**: если конкретное зеркало сдохло → ZombieTub сам перепрыгивает на другое; в крайнем случае поднимает официальный плеер ютуба (там может быть реклама — приложение прямо об этом пишет).
- ⚠️ Публичные некоммерческие зеркала бывают нестабильны или закрыты — это не баг приложения. В «О программе» есть кнопка «Проверить статус зеркал» — реально пингует все 8 и пишет, кто жив.

## Функции (все кнопки настоящие)

- **Поиск** настоящих видео (зеркальный поиск + вставка прямой ссылки youtube.com/watch / youtu.be / shorts)
- **Главная** с чипсами-категориями: Все подряд (= Восхождение), Музыка, Игры, Фильмы ужасов, Зомби, Наука, Юмор, Технологии, Аниме
- **Восхождение** (тренды по региону)
- **Просмотр**: плеер (прокси-поток → iframe-фоллбек), статистика, описание, теги (клик = поиск), похожие видео
- **Комментарии** (реальные, с зеркала)
- **Каналы**: страница канала, описание, видео, подписка
- **Орда (подписки)**: локальный список + «Кормить» (лента канала) + «Кикнуть» (с модалкой)
- **Локальные списки**: Пожранное (история), Вкусное (лайки), Отложить — всё в localStorage, ничего не уходит в сеть
- **Счётчики** в сайдбаре (орда / пожранное / вкусное / отложить)
- **Шафл-рулетка** (случайное слово → случайное видео)
- **Настройки**: регион трендов, своё зеркало, прокси-потоки вкл/выкл, трупо-факты вкл/выкл, «стереть всё» (с модалкой)
- **Журнал зеркал**: приложение помнит, кто отвечал, живое зеркало двигается в начало каскада
- **Мобильная версия**: нижняя навигация, адаптивные сетки, safe-area
- **Горячие клавиши**: `/` или Ctrl+K — поиск, Esc — назад

## Честность запуска

- Приложение — **классический JS** (не ES-модуль), работает в любом свежем Chrome / Firefox / Edge.
- Коллектор ошибок (`window.__ZTerrs`) ловит всё, что упало.
- **Сторож запуска** — отдельный скрипт-блок: если главный скрипт не выполнился (старый браузер, обрезанный файл), показывает красный экран с ошибкой и подсказкой, вместо немого чёрного экрана.

## Приватность

- Без аккаунтов, без серверов, без трекеров.
- Всё личное (подписки, история, лайки, отложенное, настройки) — только в localStorage твоего браузера.
- Кнопка «Стереть всё» в настройках убирает всё насовсем.

## Запуск

Скачай `zombie-tub/index.html` и открой локально в браузере (двойной клик). GitHub-страница файла не запускает приложение — это просто просмотр кода.

## Проверки

- Разбор документа: 3 скрипт-блока (коллектор, приложение, сторож), `node --check` — синтаксис ОК во всех.
- Внутри кода нет «отравленных» `</script>`-последовательностей (урок Gektar-чёрного-экрана).
- Полный boot-тест под JSDOM с мок-зеркалами: **56/56 PASS** — boot, каскад зеркал с failover, поиск, прямая ссылка, просмотр + фоллбек-плеер + комментарии + похожие, лайки/отложить/подписки/кормить/кикнуть, локальные списки, шафл, горячие клавиши, чипсы, настройки, статус зеркал, «стереть всё», честная офлайн-плашка при мёртвых зеркалах, сторож показывает overlay при поломанном скрипте.
